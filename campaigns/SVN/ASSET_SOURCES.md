# Redistributable asset sources

## Player F-15 model

- Files: `15FLT/shape_000_LiSiCin_Stolen_F15.glb`,
  `15FLT/shape_006_SVN_Custom_Aircraft_006.glb`, and
  `15FLT/shape_007_SVN_Custom_Aircraft_007.glb`
- Source: `f15_eagle` from [fighter jets](https://opengameart.org/content/fighter-jets)
- Author: Captain_Ahab_62
- License: CC0 1.0
- Changes: selected the F-15 mesh, mapped its axes to F-15 SE2 coordinates,
  centered it, and uniformly scaled each copy to fit its original slot bounds.
- Original source archive: `basic_replacements.blend.zip`

The source model's aspect ratio is preserved. No textures or geometry from the
original commercial game are included in this replacement GLB.
